# Video2Doc — видео в Word

[![Лицензия: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Берёт видеофайл, расшифровывает речь локальной моделью GigaAM v3 (Сбер), вырезает кадр
каждые N секунд и собирает `.docx` с отметками времени. Без облака, без ИИ-пересказа:
никаких итогов и выводов — только время, кадр и сказанный текст.

```
Название видео
Расшифровка: GigaAM v3, кадр каждые 20 с, как в видео, 25.11.2026

[00:00:00]  <кадр>  текст речи за первые 20 секунд
[00:00:20]  <кадр>  текст речи за следующие 20 секунд
…
```

- **Папка или отдельные файлы** — можно добавить целую папку (с подпапками или без) или
  перетащить видео на exe. Форматы: mp4, mkv, avi, mov, webm, wmv, m4v, flv, mpg, ts.
- **Две модели** — «точнее» (`v3_e2e_rnnt`) и «быстрее» (`v3_e2e_ctc`), обе с пунктуацией.
- **Кадры по желанию** — с переключателем «Сохранять кадры» выключенным получается только
  текст с отметками `[чч:мм:сс]`, это быстрее и файл маленький.
- **Качество кадров** — «Как в видео» (читается мелкий текст на записи экрана) или
  «Сжатые, 960 px» (документ в 3–4 раза легче).
- **Без «э-э»** — звуки-заполнители («э-э», «ммм», «а-а») убираются; слова «ну», «то есть»
  не трогаются.
- **Проверка до старта** — доступ на запись, место на диске, ffmpeg, модель.
- **Журнал и отчёт** — журнал копируется; кнопка «Отчёт для разработчика…» собирает
  окружение и ошибки в один txt.
- **Просмотрщик** — `ПросмотрDOCX.html` открывается в браузере (Chrome, Edge, Firefox) без
  установки и интернета: оглавление по отметкам времени, поиск, масштаб, кадры на весь экран
  с приближением, тёмная тема. Файл читается только в браузере и перечитывается сам, когда
  `.docx` меняется на диске.

## Скачать

Готовая программа — в разделе [**Releases**](../../releases/latest): архив
`Video2Doc-<версия>-win64.zip`, распаковать в любую папку и запустить `Video2Doc.exe`.
Установка не нужна, папку можно переносить и передавать целиком.

Модели в архив не входят. Выбранная модель (~450 МБ) скачивается один раз при первой
обработке: с CDN Сбера, а если он недоступен — из релиза
[`models-v1`](https://github.com/vitrman/voice2text/releases/tag/models-v1) Voice2Text.
Если на компьютере уже стоит [Voice2Text](https://github.com/vitrman/voice2text), его модели
используются без скачивания. Для работы без интернета положите `<модель>.ckpt` и
`<модель>_tokenizer.model` в папку `models` рядом с `Video2Doc.exe`.

Windows может показать SmartScreen (exe не подписан): «Подробнее» → «Выполнить в любом случае».
Если антивирус запрещает программе запись файлов, добавьте `Video2Doc.exe` в доверенные.

## Требования

- Windows 10/11 x64, 8 ГБ ОЗУ, видеокарта не нужна.
- ~2 ГБ на диске: ~800 МБ программа с ffmpeg + ~450 МБ на каждую модель.
- Интернет — только для первого скачивания модели.

## Из исходников

Нужен Python 3.12 и `ffmpeg` в `PATH`.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe video2doc_app.py
```

Параметры запуска: `video2doc_app.py [файлы/папки ...] [--auto]`, где `--auto` сразу
обрабатывает переданные пути и закрывает окно.

## Сборка exe

```powershell
.\build.ps1             # папка dist\Video2Doc
.\build.ps1 -Release    # плюс dist\Video2Doc-<версия>-win64.zip и .sha256 для релиза
```

Параметры: `-Python` — интерпретатор с зависимостями, `-Ffmpeg` — какой `ffmpeg.exe` положить
в `bin\`, `-WithModels <папка>` — положить модели в сборку для работы без интернета.

## Где что лежит

| Что | Где |
|---|---|
| Настройки, журнал, журнал ошибок | `%LOCALAPPDATA%\Video2Doc` |
| Скачанные модели | `%LOCALAPPDATA%\Video2Doc\.cache\gigaam` |
| Готовые `.docx` | рядом с видео или в выбранной папке |

## Устройство

- `video2doc_app.py` — окно, проверки, обработка: ffmpeg вынимает звук (16 кГц моно) и кадры,
  GigaAM распознаёт звук кусками по паузам, текст раскладывается по отрезкам шага,
  `.docx` собирается напрямую (OOXML), без сторонних библиотек.
- `asr_engine.py`, `model_fetch.py`, `postprocess.py`, `paths.py` — движок из
  [Voice2Text](https://github.com/vitrman/voice2text): загрузка и проверка модели (md5),
  скачивание с докачкой, нарезка звука, чистка заполнителей.
- `make_icon.py` — рисует `video2doc.ico`.
- `ПросмотрDOCX.html` — просмотрщик готовых документов: один файл, без библиотек
  (ZIP читается через `DecompressionStream`, разметка Word разбирается в браузере).
