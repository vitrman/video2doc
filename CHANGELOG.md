# Изменения

## 1.4 — первая публичная версия

- Модели больше не лежат в архиве программы: выбранная модель скачивается один раз при первом
  запуске (CDN Сбера, запасной источник — релиз `models-v1` на GitHub). Если уже стоит
  Voice2Text, его модели используются без скачивания. Модели в папке `models` рядом с exe
  по-прежнему находятся первыми — так можно работать совсем без интернета.
- Движок распознавания входит в репозиторий, сборка не зависит от исходников Voice2Text.

## До 1.4 (внутренние сборки)

- Речь из видео → .docx с отметками времени и кадрами через заданный шаг.
- Выбор модели: GigaAM v3 «точнее» (RNNT) или «быстрее» (CTC).
- Чистка звуков-заполнителей («э-э», «ммм», «а-а»).
- «Сохранять кадры»: без него — только текст с отметками времени.
- «Качество кадров»: «Как в видео» или «Сжатые, 960 px».
- Проверка доступа к папкам и места на диске до начала обработки.
- Выбор папки для .docx, отчёт для разработчика, журнал ошибок, копирование журнала.
