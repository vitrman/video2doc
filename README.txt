Video2Doc 1.4 — видео в Word
============================

Расшифровывает речь из видео моделью GigaAM v3 от Сбера (распознавание идёт на вашем
компьютере, звук никуда не отправляется) и делает кадр каждые N секунд.
Результат — .docx рядом с видео, с тем же именем:
  заголовок, строка «Расшифровка: модель, шаг, дата», затем блоки
  [00:00:20]  кадр  текст речи за эти 20 секунд
Итогов и выводов нет.

Модели (выбор — справа в «Настройках», запоминается)
  GigaAM v3 — точнее       v3_e2e_rnnt   449 МБ   по умолчанию; лучше слова и знаки
  GigaAM v3 CTC — быстрее  v3_e2e_ctc    442 МБ   быстрее на слабом процессоре, ошибок чуть больше
Модель скачивается один раз, при первой обработке (нужен интернет), и хранится в
%LOCALAPPDATA%\Video2Doc\.cache\gigaam. Если установлен Voice2Text, берутся его модели.
Без интернета: положите файлы <модель>.ckpt и <модель>_tokenizer.model в папку models
рядом с Video2Doc.exe.

Как пользоваться
1. Запустите Video2Doc.exe (или перетащите на него видео/папку).
2. «Добавить файлы…» или «Добавить папку…».
3. Справа: модель, «Сохранять кадры» (выключите — будет только текст, быстрее),
   «Качество кадров»: «Как в видео» (исходное разрешение, читается мелкий текст на записи экрана)
   или «Сжатые, 960 px» (документ в 3–4 раза легче), шаг, «Искать в подпапках»,
   «Перезаписывать готовые .docx», «Убирать э-э, ммм, а-а» (слова «ну», «то есть» не трогаются).
   «Куда сохранять .docx» — рядом с видео или в выбранную папку.
4. «Старт». Перед обработкой программа проверяет доступ к папкам и место на диске.
   Видео с готовым .docx пропускаются, если не включена перезапись.

Состав папки (копировать целиком)
  Video2Doc.exe   — программа
  _internal\      — Python, torch, GigaAM, оформление
  bin\ffmpeg.exe  — работа с видео
  ПросмотрDOCX.html — просмотр готовых .docx в браузере: оглавление по времени, поиск,
                      кадры на весь экран. Откройте его и перетащите .docx в окно.
Настройки, журналы и скачанные модели: %LOCALAPPDATA%\Video2Doc.
При ошибке нажмите «Отчёт для разработчика…» и отправьте получившийся txt-файл.

Если пишет «Нет доступа на запись»: антивирус (например Kaspersky) может запрещать запись
неизвестным программам — добавьте Video2Doc.exe в доверенные программы антивируса.
Windows может показать SmartScreen: «Подробнее» → «Выполнить в любом случае».

Требования: Windows 10/11 x64, 8 ГБ ОЗУ, ~2 ГБ на диске. Видеокарта не нужна.
Скорость: модель грузится ~5 с, минута видео обрабатывается за несколько секунд (зависит от процессора).

Исходный код и новые версии: https://github.com/vitrman/video2doc
